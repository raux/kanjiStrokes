# kanjiStrokes

A calm, single-page web prototype for learning kanji stroke order through slow SVG brush animations.

## Run locally

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

The initial prototype presents **木** (*き / もく*, “tree”) with a replayable four-stroke animation, reduced-motion support, and a paper-and-ink visual treatment.
